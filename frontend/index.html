What it does
You describe a project. 8 specialized agents run the full SDLC automatically
Clarifier scores ambiguity, asks targeted questions if needed
BA → Scrum → Dev → QA — writes code, runs pytest, self-heals on failure (up to 3 retries)
Git Agent commits each sprint with tags; GitHub Agent pushes and opens a PR
DevOps Agent generates Dockerfile, docker-compose, and CI/CD pipeline
Frontend is a single HTML file — no build step. Deployed on Railway
Self-Healing Dev↔QA Loop

QA runs pytest
↓ tests pass? → next ticket ✓
↓ tests fail? → error injected into
Developer prompt → full rewrite
↓ up to 3 attempts
still failing? → skip, continue
